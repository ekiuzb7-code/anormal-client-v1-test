## 3. FakeLagV2 / BackTrackV2
**FakeLagV2:**
- `recoilTime` amalda bir martalik edi (chronometer faqat onEnable da yozilardi) → endi har
  flush da `chronometer = now`, ya'ni burstlar orasidagi haqiqiy minimal tanaffus.
- `Delay` default 300..600 → **100..200** (LiquidBounce default). Katta kechikish server
  position-correction javobini keltirib chiqarardi — "borib kelib" effekti shundan.
- Yiqilish paytida (`velocity.y < -0.4`) lag qilinmaydi — server uchayotgan deb teleport qilardi.
- `MAX_QUEUED = 40` — burst chegarasi.
- Dynamic range `range.random()` bilan (LB kabi).

**BackTrackV2:**
- **Kritik:** `entityIdOf() == -1` "noma'lum" degani, lekin kod uni "target" deb hisoblab
  paketni ushlab qolardi → **hamma** entity (item, boshqa o'yinchilar, moblar) muzlardi.
  Endi `id != -1 && id == target.getId()`.
- HurtTime 0 → "doim pauza" edi; endi `hurtTime > 0` sharti bilan.
- `Chance` faqat enable/attack da o'ralardi — bir marta o'tmasa butun jangda ishlamasdi.
  Endi har sikl oxirida qayta o'raladi.
- `MAX_QUEUED = 60`.

## SafeWalk
**Asosiy xato:** `Box.expand(0, -stepHeight, 0)` — `expand` simmetrik, ya'ni minY **yuqoriga**
suriladi va probe box kichrayadi → deyarli hamma joyda "chekka" deb topilardi (blok markazida
ham egilardi). Endi `probeBox()` boxni aniq quradi: X/Z bo'yicha `edgeDistance` ga kichraytirib,
`minY - stepHeight` gacha pastga tushiradi (Wurst `expandTowards` bilan bir xil).

## Sneak-Tap Bridging
- **`Build Direction`** (yangi, default `Follow Input`): target endi **haqiqiy WASD input**
  yo'nalishiga qarab tanlanadi. S bosilsa orqaga quriladi. Full Auto'da kamera ishlatiladi.
- **`Rotation Mode`** (yangi, default `Silent`): klikdan oldin o'yinchi blokka qarab buriladi
  (`atan2(-dx,dz)` / `-atan2(dy,horiz)`), keyin Silent rejimida yaw/pitch qaytariladi.
  Ilgari umuman burilmasdi — server uchun "qaramay qo'yish" edi.
