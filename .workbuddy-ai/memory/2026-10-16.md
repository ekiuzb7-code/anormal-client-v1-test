## 1) BlockESPHelper / BlockScanner'ga migratsiya (7 modul)
Oldin qo'lda kubik sferada skanerlaydigan, har sweep'da `clear()` qiladigan modullar
byudjetli dvigatelga o'tkazildi (BedESP/PortalFinder/ShulkerFinder naqshi bo'yicha).

| Modul | Usul | Izoh |
|---|---|---|
| BannerESP | `BlockESPHelper` | Matcher rang filtri bilan |
| StrongholdFinder | `BlockESPHelper` | Chat-log faqat yangi topilgan freym uchun (`prevSize` + `logged`) |
| SignESP | `BlockScanner` (Map<BlockPos,String>) | Har tikda re-validatsiya, 3 o'qda markaz |
| BlockESPCoord | `BlockScanner` (Map<BlockPos,String>) | Blok nomi saqlanadi |

(mavjud lug'at kaliti, "the" bilan).

## 3) Build / CI tuzatish (MUHIM)
Muammo: `build.gradle` loom `1.14-SNAPSHOT` talab qiladi, lekin wrapper `gradle-8.10.2` edi
-> "No matching variant ... plugin.api-version 9.2.0 vs 8.10.2".
Eski loom (1.8) esa `Unsupported unpick version` berdi (1.21.11 mapping'ni tushunmaydi).

Yechim:
- `gradle/wrapper/gradle-wrapper.properties` -> **gradle-9.8.1-bin.zip**
- `gradle/wrapper/gradle-wrapper.jar` -> qo'shni loyihadan ko'chirildi (yo'q edi)
- `build.gradle` -> loom **1.14-SNAPSHOT** (1.14.10 ga yechiladi)
- `.github/workflows/build.yml` -> endi wrapper ishlatadi: `./gradlew build --no-daemon`
  (setup-gradle@v4 versiyasiz, `chmod +x gradlew`, artifact `build/libs/AnormalClient-*.jar`)

Tekshirildi lokal: `./gradlew build` **BUILD SUCCESSFUL** (Gradle 9.8.1, Loom 1.14.10).
Chiqish: `build/libs/AnormalClient-1.0.0.jar` (~1.1 MB, remapped).
`gradlew` LF-only, `.gitattributes` binary fayllarni himoya qiladi — CI'da muammo yo'q.
