# Music Player (LEGIT HUD) — yangi modul

## Fayllar
- `music/MusicTrack` — path + **lazy** ID3v2 parsing (TIT2/TPE1/TALB/APIC). Lazy bo'lishi shart:
  har faylning birinchi 512KB ini o'qish queue qurishda frame hitch beradi.
- `music/Mp3Probe` — birinchi frame'dan bitrate + ID3 hajmi → davomiylik taxmini.
- `music/MusicEngine` — SourceDataLine + bitta worker thread; pause/seek/volume bir xil ishlaydi.
  MP3 = JLayer `Bitstream`+`Decoder` → 16-bit PCM. WAV/AIFF/AU = JDK dekoderlari.
  Volume `MASTER_GAIN` (dB, 20*log10) — linear slider quloqqa noto'g'ri tuyuladi.
- `music/MusicLibrary` — queue, shuffle, loop (OFF/ALL/ONE), tarix (prev uchun),
  `config/anormal/music.txt` ga saqlash.
- `music/AlbumArt` — cover → NativeImageBackedTexture, 24 tagacha kesh (VRAM).
- `module/impl/legit/MusicPlayer` — HUD karta 268x92 (base), matrix scale bilan.
- `gui/MusicPlayerScreen` — playlist: Add Files / Add Folder / path maydoni / ro'yxat
  (chap klik = play, o'ng klik = remove) / shuffle / loop / volume.
- `MouseMixin.onMouseButton` — karta ustidagi klik `ci.cancel()` (aks holda blokga uriladi).

## MusicPlayer ↔ HUD editor

**Savol**: musiqa kartasi HUD editor'da bormi?
**Javob**: HA — editor `findPosSettings()` orqali **avtomatik** topadi (public NumberSetting
maydonlarida "pos"+"x"/"pos"+"y" qidiradi; MusicPlayer'da `posX`/`posY` bor).
**LEKIN** o'lchami noto'g'ri edi: `measureElement` da case yo'q edi → `defaultSize` fallback
`{90,14}` → karta 268×92 bo'lsa ham drag qutisi 90×14 (kichkina, ko'rinmas).

**Sabab**: editor `RenderUtils.beginMeasure/endMeasure` bilan o'lchaydi, lekin bu faqat
`RenderUtils.fill` chaqiruvlarini kuzatadi. MusicPlayer esa `ctx.fill` + matrix scale ishlatadi
→ o'lchov ko'rmaydi → fallback.

**Fix**: `measureElement` va `defaultSize` ga `MusicPlayer` case qo'shildi —
`(int)(268*scale) × (int)(92*scale)` (modulning `scale` sozlamasidan).

Build SUCCESSFUL.

## MusicPlayer drag (ildiz sabab) + HUD modullar modernizatsiyasi (1-batch)

### MusicPlayer "pastga yurib ketyapti" — ILDIZ SABAB
Karta `matrices.pushMatrix(); translate(x,y); scale(s,s)` ichida chizilardi. `ctx.fill` **matritsa
qo'llanmagan** koordinatalarni oladi → `DrawContextMixin` o'lchovi har doim ~(0,0) 268x92 qaytarardi.
Natijada `moveBy` da `frameY≈0` → `minDy = -0` = **tepaga surish bloklangan**, `maxDy` katta →
faqat pastga ketardi.

**Fix**: butun karta **absolute koordinatalarga** o'tkazildi — `sx()/sy()/sw()` helperlar
(`gx + base*gs`). Matritsa faqat **matn** uchun ishlatiladi (`textS`, push→translate→scale→draw),
matn `fill` emas, shuning uchun o'lchovni buzmaydi.

card(ctx, tr, x, y, label, value, accent, centerOnX)

- label dim (#8A8A96), value **bold** (#E8E8EC) o'ngga tekislangan
- balandlik 16px, `cardWidth()` bilan avtomatik o'lcham

**Modernizatsiya qilindi (6 ta)**: FPS, Clock, Compass, DirectionHUD, BlockCounter, ItemCounter.
