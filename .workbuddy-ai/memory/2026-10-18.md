## MUHIM: "code too large" xatosi (kelgusi ishlar uchun)
Lug'at 3447 yozuvga yetganda `Uz.java`/`Ru.java` **"code too large"** berdi.
Sabab: **barcha static maydon inicializatorlari bitta `<clinit>` metodiga yig'iladi**
va u 64 KB dan oshdi. Massivni bir necha maydonga bo'lish **yordam bermaydi**.
**Yechim:** har bir bo'lakni **alohida metodda** qurish:
```java
private static String[][] d1() { return new String[][] { ... }; }
private static final String[][][] CHUNKS = { d1(), d2(), ... };
static void load(Map<String,String> m) {
    for (String[][] c : CHUNKS) for (String[] e : c) m.put(e[0], e[1]);
}
```
450 yozuvdan 8 ta bo'lak.
