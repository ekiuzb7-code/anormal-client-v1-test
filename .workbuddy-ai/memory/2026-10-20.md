## Aimbot tuzilishi
- **Mode**: Regular (kamera) / **Silent** (`PlayerMoveC2SPacket.LookAndOnGround(FFZZ)`,
  kamera qimirlamaydi, `lastSent` bilan dedupe).
- **Smoothing**: Ease Out Cubic / WindMouse / Linear + `Smoothness` 0..100.
- **Bones** (MultiSelect): Multipoint, Head, Body, Left/Right Arm, Left/Right Leg.
- **GCD Fix**: `f = sens*0.6+0.2; gcd = f^3*8*0.15` — delta shu qadamga yumaloqlanadi.
- **Prediction**: `velocity * ticks` (tez nishonlar uchun).
- Target: FOV konus + Range + LOS + players/mobs/animals + Friends + `TargetFilter.isValid`.
- **Auto Attack** (default OFF): CPS + `getAttackCooldownProgress(0.5f) >= 1`;
  silent rejimda avval look paketi, keyin `attackEntity` (server shu rotatsiyani tekshiradi).

`isHovering()` endi `lastAim` (yuborilgan rotatsiya) bo'yicha tekshiradi, kamera bo'yicha emas.
`Aim Speed` (1..20) endi haqiqatan ishlatiladi: `smoothness = 1 - (speed-1)/19`.

## AutoMace / WindCharge / Surround qayta yozildi

### AutoMace — serverda ishlamasligining 3 sababi
1. **Reach:** `Aim Range` default 4.5, server esa ~3.0 qabul qiladi → 3 blokdan uzoq har bir hit
   jimgina tushib qolardi. Endi `reach()` = `min(setting, mc.player.getEntityInteractionRange())`.
2. **Silent aim paket yubormasdi:** yaw/pitch o'rnatib, uradi, o'sha tikda qaytarardi — server
   eski rotatsiya bilan tekshirardi. Endi `rotation.send()` **attack'dan oldin**.
3. **LOS yo'q edi:** devor ortidan uraverardi. Endi `Line Of Sight` + `TargetFilter` + Friends.

Qo'shimcha: `Re-equip Elytra` endi haqiqatan `interactItem` bilan elytra'ni kiyadi (avval faqat
slotni tanlardi). Stun Slam 2 bosqichli: bolta → `Stun Delay` → mace (avval mace zarbasi umuman
bo'lmasdi). Nishon tanlash endi crosshair burchagi + masofa bo'yicha (`angle + dist*4`).

### WindCharge — nega serverda ishlamasdi
Pitch 90 ga o'rnatilib, **o'sha tikda** `interactItem` chaqirilardi, lekin look paketi
yuborilmasdi → server eski pitch bilan oldinga tashlardi. Endi `rotation.send()` item
ishlatishdan **oldin**. `silentAim` ham endi haqiqatan ishlaydi (avval umuman aim qilmasdi).
`setVelocity(..., 0.1, ...)` olib tashlandi — bu velocity spoofing, server tuzatadi.
Yangi: Mode (Jump Boost/Throw Only), Aim Pitch, Restore Pitch, Jump Ticks, Delay, Auto Disable.
Holat mashinasi: IDLE → THROWING → RECOVER (jump tugmasi faqat o'zimiz bosgan bo'lsak bo'shatiladi).

### Surround — nega ishlamasdi

→ klik invalid, hech narsa qo'yilmasdi. Endi 6 yo'nalish bo'yicha har qanday solid qo'shni
qidiriladi + reach tekshiriladi + rotatsiya yuboriladi (silent).
Yangi: **Auto Center** — blok markaziga WASD bilan yuradi (a surround faqat markazdan ishlaydi;
faqat o'zimiz bosgan tugmalar bo'shatiladi), Block Mode (Obsidian Only / Blast Resistant / Any),

## Rotatsiya asosiy xato + HitSwap/TargetLock/AutoPearl/Crosshair

### RotationController — silent rejimda silliqlash yig'ilmagan
`step()` har tikda kameradan qayta boshlanardi. Silent rejimda kamera qimirlamaydi →
rotator har tikda **bir xil nuqtadan** boshlanib, nishonga hech qachon yetib bormasdi
(EaseOutCubic faqat qolgan burchakning 16%ini bosib o'tardi va to'xtardi).
**Fix:** `internal` holat saqlanadi; visible rejimda kamera, silent rejimda ichki holat
ischlatiladi (kamera 35° dan ko'p chetlashsa — o'yinchi o'zi burildi → qayta bog'lanadi).
`send()` endi `internal` ni ham yangilaydi.

### AutoMace
`Silent Aim` default **false** bo'ldi — endi belgisi ko'rinadi (visible). Ayttirilgandek
ko'rinishi "buzilgan" degan shikoyat aslida silent aim tabiati edi.
`step(..., silent)` endi to'g'ri flag bilan.

### HitSwap — butunlay ishlamasdi
`onTick` (END tick) da slot almashardi, lekin klik allaqachon paketga aylangan edi →
har hit eski qurol bilan chiqardi. **Fix:** `ClientPlayerInteractionManagerMixin` ga
`attackEntity` HEAD hook qo'shildi → `HitSwap.beforeAttack(target)` paket yuborilishidan
OLDIN ishlaydi + `UpdateSelectedSlotC2SPacket` qo'lda yuboriladi (`syncSelectedSlot` private).

### TargetLock — hech narsa qulflamasdi
`ArrayList<String> entityFilter` e'lon qilingan, lekin **hech qachon to'ldirilmagan** →
Whitelist: `true == false` = false, Blacklist ham shunday. Barcha nomzodlar rad etilardi.
**Fix:** ro'yxat olib tashlandi; filtr endi `Players/Mobs/Animals` toggle'laridan hisoblanadi
(Whitelist = faqat belgilanganlar, Blacklist = tashqaridagilar). Qo'shimcha: RotationController
(silent + GCD), Bone nuqtalari, LOS, TargetFilter, `Lock On Attack` (attack hook orqali),
`Pause` rejimi. `Silent` avval faqat sozlama edi — ishlatilmagan.

### AutoPearl
Silent rejimda umuman aim qilmasdi va paket yubormasdi → server eski yo'nalishda tashlardi.
Endi `rotation.send()` `interactItem` dan oldin.

### CustomCrosshair
`Highlight Target` + `Target Color` qo'shildi — crosshair entity ustida bo'lsa rangi o'zgaradi
(rang ustuvorligi: target > rainbow > cooldown > base). PvP uchun eng tez "mo'ljaldaman"
signali.

## Aimbot "aylanib" xatosi — EaseOutCubic delta semantikasi

Sabab: `EaseOutCubic.step(from, target, config, deltaTicks)` da `deltaTicks` — rotatsiya
BOSHLANGANidan beri o'tgan vaqt (trident'da shunday). Biz esa har tikda `1.0f` yuborardik →
`fraction = 1-(1-1/31.9)^3 = 0.091` doimiy → har tikda qolgan burchakning 9%ini bosib
o'tardi. Harakatlanayotgan target bilan bu "sekin aylanib turish" sifatida ko'rinardi.

**Fix:** `RotationController` endi `elapsed` ni o'zi hisoblaydi (target almashganda reset,
threshold 60° — 30° juda tor edi, yurayotgan target uni har tikda reset qilib yuborardi).
EaseOutCubic `elapsed` oladi, WindMouse/Linear `1.0f` (ular per-tik integrator).

Defaults: Aimbot smoothness 55→30, KillAura 60→35 (55 = 9%/tik, 30 = ~49%/tik).
